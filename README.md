# Escape School 0.7 — Excel база

## Еднократна настройка
Качете целия пакет **със запазени папки** в съществуващото GitHub хранилище escape-school. Нужни са `index.html`, `questions.json`, `questions.xlsx`, `tools/convert_questions.py` и `.github/workflows/questions.yml`. В GitHub Settings → Actions → General разрешете Workflow permissions → **Read and write permissions**. Pages остава `main / (root)`.

## След това сменяйте само Excel
Отворете `questions.xlsx` на компютъра, заменете всички редове под заглавията и запазете. В хранилището GitHub качете новия файл `questions.xlsx` на негово място, в главната папка. GitHub → Actions показва дали автоматичната проверка е успешна. При успешна проверка `questions.json` се обновява и новите въпроси се появяват за учениците след презареждане на играта (обикновено няколко минути след автоматичното публикуване).

**Важно:** В GitHub уеб интерфейса за замяна на файл с идентично име може да се наложи да използвате `Add file → Upload files` и да потвърдите замяната, или GitHub Desktop. Не качвайте Excel в подпапка.

## Формат
Колони: `Въпрос | А | Б | В | Г | Верен`; верният е една буква (А/Б/В/Г). Поне 7 пълни реда. Празни или неправилни клетки прекратяват автоматичната замяна. Старите валидни въпроси остават онлайн, когато проверката е неуспешна. Няма учителски акаунт: право за промяна има само този, който може да записва файлове в GitHub хранилището.

Ново учебно съдържание = нов набор; напредъкът на ученика се нулира автоматично при следващо зареждане на различната база. Старите мисии/карта/движение остават. Enter потвърждава диалозите; стрелки нагоре/надолу избират отговор (Enter потвърждава). Всички ученици играят самостоятелно.
