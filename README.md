# Escape School 0.3 — Народните будители

Работеща самостоятелна HTML5 игра за 5. клас, без зависимости и сървър.

## Стартиране
Отворете `index.html` в браузър. Използвайте стрелките или WASD на компютър и бутоните под картата на телефон.

## Публикуване чрез GitHub Pages
1. Създайте публично хранилище `escape-school` в GitHub.
2. Качете `index.html` и `README.md` в главната директория.
3. Отворете Settings → Pages → Build and deployment → Deploy from a branch.
4. Изберете `main` и `/ (root)` и запазете.
5. Адресът обикновено е `https://ВАШЕТО-ИМЕ.github.io/escape-school/`.

## Редакции
Променяйте въпросите в масива `const Q` в `index.html`, като запазвате структурата на елементите (`q`, `a`, `ok`). Винаги пазете резервно копие преди промяна.

Изходният код в `index.html` е непроменено копие на Escape_School_0_3_Buditeli.html.
